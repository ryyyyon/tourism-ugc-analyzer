# 銚子市のインバウンド向け情報発信戦略：YouTubeのUGC分析

株式会社KIYONO 長期インターン選考課題（課題1：UGC分析とマーケティング戦略立案）の提出物です。

千葉県銚子市を対象に、YouTube上の観光動画を「国内向け／海外向け」に分けて分析し、インバウンドを増やすための情報発信戦略を導きました。比較対象として、江ノ島・鎌倉（インバウンドに成功している地域）と大洗（規模・立地が近い港町）も同じ仕組みで分析しています。設定ファイルを1つ足せば、どの観光地でも同じ分析ができます。

## 分かったこと（要点）

- **銚子の海外への入口は、銚子電鉄ほぼ1本**：海外向けの再生の91%が鉄道。集中度（HHI）は銚子0.83、大洗0.33、鎌倉0.21。上位3チャンネルに海外の再生の82%を依存している。英語・台湾・韓国の3言語圏で、別々のクリエイターが「煎餅を売って生き延びる鉄道」という逆境の物語を取り上げている。
- **訪日客回復の波に乗れていない**：2023年以降、鎌倉は海外向けの割合が5〜6割に増えたが、銚子は2〜3割のまま。海外向けの数は大洗と同程度なのに、再生中央値は銚子218回、大洗437回、鎌倉7,153回。
- **魚は海外にまったく届いていない**：国内ではグルメが再生の約4割を占める最強のテーマなのに、イワシ・マグロ・金目鯛の名前は海外向けの動画に0本。一方、醤油と煎餅は海外でも知られている。
- **海外では「何を作るか」より「誰が作るか」**：回帰分析で、チャンネルの登録者数が10倍になると再生数は約3倍。テーマの効果の多くは作り手の規模で説明できた。
- **絶景・灯台・言語不要の動画は、単体では最も見られにくい**。

## アプローチと工夫した点

- **データの選択**：Instagramの公式APIはハッシュタグ検索に審査が必要なため、無料で再生数とコメントまで取れるYouTube Data APIを選んだ。スクレイピングは規約違反になるため使っていない。
- **言語判定の改良**：投稿者の言語設定が英語のままの日本語動画、漢字だけの中国語タイトル（ライブラリが韓国語と誤判定）、広東語、2か国語のタイトルなど、データを見るたびに見つかった誤りに合わせて独自のルールを作った。タイトルで判断できないものは、コメントの言語で補正する。
- **視聴者層の推定**：YouTubeでは視聴者の国籍は投稿者しか見られないため、コメントの言語分布を代理指標にした。
- **ノイズの除去**：「銚子」という名前が入っているだけの動画（津波速報、演歌、回転寿司チェーン、楽器の「調子」、横浜の「屏風浦」駅など）を除いた。何がノイズかは地域で違う（銚子ではアニメはノイズ、大洗ではガルパンの聖地巡礼が観光の柱）ため、共通の辞書と地域ごとの辞書を重ねる設計にした。
- **統計での検証**：地域・テーマ・形式・言語・経過日数を同時に入れた重回帰分析で、他の条件をそろえたときの効果を推定した。さらにチャンネル登録者数を加えて、「人気のチャンネルが作っただけ」の効果を取り除いた（頑健性の確認）。
- **分類の精度の検証**：90本を、分類の結果を見せずに人の目で判定し、精度を測った。観光判定89%、国内・海外90%、テーマ62%（銚子は86%）。誤りの分析からルールを改善し、その副作用（2か国語のルールが効きすぎて銚子の海外向けが倍増）も見つけて直した。最後に、ルールを変えても主要な結論が変わらないことを確かめた。

## 使い方

### 準備

```
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

`.env.example` を `.env` にコピーし、YouTube Data API v3 のAPIキーを書きます（`.env` はGitHubに上げません）。

### データの取得と分析

```
python run_pipeline.py --region choshi enoshima_kamakura oarai   # 動画・コメントの取得とテーマ分類
python fetch_channel_stats.py                                    # チャンネル登録者数の取得
python compare_regions.py                                        # 地域の比較
python analyze_trends_accounts.py                                # 年別トレンドとチャンネル分析
python analyze_engagement_keywords.py                            # キーワード集計と回帰分析
```

クォータの目安は1地域あたり約2,100ユニット（無料枠は1日10,000ユニット）です。

### 分類の精度の検証

```
python make_validation_sample.py      # 検証用の動画を選ぶ
python make_label_gallery.py          # サムネイルを見ながら正解を記入するページを作る
python evaluate_validation.py         # 精度を計算する（--current で今のルールで再計算）
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `check_youtube_volume.py` | 動画の検索・取得、言語と関連性の判定 |
| `fetch_comments.py` | 上位動画のコメントの取得と言語分布の集計 |
| `classify_themes.py` | テーマ分類、国内・海外の比較、空白地帯の抽出 |
| `run_pipeline.py` | 上の3つをまとめて実行 |
| `compare_regions.py` | 複数地域の比較（HHI、言語、動画の形式など） |
| `analyze_trends_accounts.py` | 年別トレンド、チャンネルへの依存度、公式チャンネル |
| `analyze_engagement_keywords.py` | スポット・特産品の集計、重回帰分析、頑健性の確認 |
| `fetch_channel_stats.py` | チャンネル登録者数の取得 |
| `make_validation_sample.py` / `make_label_gallery.py` / `evaluate_validation.py` | 分類の精度の検証 |
| `lang_utils.py` | 言語判定のルール |
| `theme_rules.py` | テーマとノイズの共通辞書、分類のルール |
| `region_config.py` | 地域設定の読み込み、データの保存先 |
| `regions/*.json` | 地域ごとの設定（検索キーワード、地名、追加の辞書、アニメ作品名、スポット名） |

### 新しい地域を追加するには

`regions/` に設定ファイルを1つ足し、`python run_pipeline.py --region <地域名>` を実行します。設定の書き方は `regions/choshi.json` を参照してください。

## データの扱い

- YouTube API Services の開発者ポリシーに従い、取得したデータ（動画の情報、統計、コメント）は**このリポジトリに含めていません**。手元でも30日を超えて保存せず、期限を過ぎたら削除するか取り直します。
- コメントの分析では、投稿者の名前などの個人情報は保存していません。

## 分析の限界

- 検索結果は、キーワードごとに関連度の高い上位100件までのサンプルで、全投稿ではありません。特に鎌倉のような人気の地域では、上位の一部しか見ていません。
- チャンネル登録者数は取得時点の値で、動画を投稿した当時の値ではありません。
- 回帰分析は相関の分析で、「そのテーマにすれば必ず伸びる」という因果までは言えません。
- テーマの分類の精度は約6〜7割で、テーマ別の数字はおおよその傾向として読む必要があります。戦略の柱になる観光判定と国内・海外の判定は約9割です。
