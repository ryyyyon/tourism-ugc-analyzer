# tourism-ugc-analyzer：YouTubeの観光動画から、インバウンド向けの戦略を考えるシステム

株式会社KIYONO 長期インターン選考課題（課題1：UGC分析とマーケティング戦略立案）の提出物です。

観光地を指定すると、YouTubeの観光動画を集めて「国内向け／海外向け」に分け、テーマや視聴者層、発信者の種類を分析し、ダッシュボードで見せるシステムです。地域ごとの違いは設定ファイル1つにまとめてあるので、地名を入れればどの観光地でも同じ分析ができます。このシステムで千葉県成田市を分析し、空港に来ている外国人を町へ迎える情報発信戦略を考えました。

## 取り組みの流れ

1. 最初は千葉県銚子市を分析した。銚子は海外で名前すら知られておらず（海外からの検索は鎌倉の6〜7%）、「知られれば本当に来るのか」という前提に答えられなかった。
2. 「名前は知られているのに、町につながっていない場所」を選ぶ条件にし、成田に決めた（2025年の外国人の入国者数は成田空港が全国1位）。
3. 銚子で作った仕組みを、地名を入れるだけでどの観光地にも使えるように作り直し、成田と比較の地域（川崎大師、川越、江ノ島・鎌倉、佐原、銚子）を分析した。

## 分かったこと（成田）

- **成田は海外では「空港」でしかない**：アメリカで成田と一緒に検索される言葉100個のうち、観光の言葉は0個。YouTubeでも「Narita Japan」などで探した動画の約6割が空港まわりだった（空港のキーワードだけで見つかった動画を除いても56%）。
- **国内と海外で、動画に出てくる言葉が違う**：海外向けではairportが41%、tokyoが24%の動画に出てくる。国内向けで17%の動画に出てくるうなぎは、海外向けの上位20語にない。
- **訪日客が戻ってから増えた動画の大半は空港まわり**：海外向けの空港・乗り継ぎの動画は、2021〜22年の11本から2025〜26年の123本に増えた。成田山は18本から41本、グルメは3本から17本。
- **海外でよく見られるのは食の動画**：チャンネル登録者数・言語・投稿からの日数・地域をそろえた重回帰分析で、寺・神社の動画を1とするとグルメは約3.8倍（95%信頼区間 2.6〜5.6倍）。祭りも約4.2倍だが、海外向けの祭りの動画は29本と少ないので兆しとして扱う。成田の海外向けの動画でも、1本あたりの再生の中央値はうなぎ6,384回（37本）、成田山569回（138本）。
- **作り手は大勢いるのに、空港ばかり撮っている**：成田の海外向けの動画を作ったチャンネルは392。乗り継ぎの動画62本のうち、町に触れたのは14本（23%）。比べたどの町でも、海外の再生の88%以上は個人の作り手で、公式（市・観光協会など）は3%以下。
- **羽田のそばの寺町、川崎大師も同じ**：羽田の乗り継ぎの動画 約140本に、一度も出てこない。

## 工夫した点

- **データの選択**：Instagramの公式APIはハッシュタグ検索に審査が必要なため、無料で再生数とコメントまで取れるYouTube Data APIを選んだ。スクレイピングは規約違反になるため使っていない。検索の多さはGoogle Trendsで補った。
- **言語判定の改良**：投稿者の言語設定が英語のままの日本語動画、漢字だけの中国語タイトル、2か国語のタイトルなど、自動判定がよく外れるので、文字の種類で判定する独自のルールを作り、コメントの言語でも補正した。
- **視聴者層の推定**：視聴者の国籍は投稿者しか見られないため、コメントの言語分布を代わりに使った（成田の海外向けの上位動画のコメントは、英語60%、韓国語18%、中国語が約1割）。
- **ノイズの除去**：名前が入っているだけの動画（成田悠輔さん、競走馬のキャラクターなど）を、地域ごとの「除く言葉」の辞書で除いた。空港の動画は捨てずに「空港」のテーマとして数えた。
- **統計での検証**：チャンネル登録者数を入れた重回帰分析で、「人気のチャンネルが作ったから伸びた」分を除いて、テーマの効果を取り出した。
- **結論を疑う**：成田だけ空港のキーワードでも動画を集めていたので、その分を除いて計算し直した（`check_robustness.py`）。本数の少ない数字は兆しとして扱った。
- **分類の精度の検証**：分類の結果を見せずに、人の目で判定した。成田の30本で、観光判定87%、国内・海外96%、テーマ64%。

## 使い方

### 準備

```
python -m venv .venv
.venv\Scripts\Activate.ps1     # Windows（PowerShell）
pip install -r requirements.txt
```

`.env.example` を `.env` にコピーし、YouTube Data API v3 のAPIキーを書きます（`.env` はGitHubに上げません）。

### 新しい地域を分析する

```
python new_region.py --ja 下呂 --en Gero --auto           # 設定ファイルを作る（韓国語・中国語・タイ語の地名はWikidataから補う）
python new_region.py --ja 下呂 --en Gero --auto --run     # そのままデータの取得と分析まで行う（約2,000ユニット）
python -m streamlit run dashboard.py                       # サイドバーの「分析の対象」に新しい地域が出る
```

作られるのは、検索キーワード（日本語・英語・韓国語・中国語・タイ語で最大10個）、地域に関係する動画の判定に使う地名、スポット名です。同じ名前の人や作品が混ざる場合は、`classify_themes.py --region <地域名>` の結果を見て `extra_noise` に足し、分類をやり直します（APIは使いません）。

### データの取得と分析（スライドの数字を出したコマンド）

```
python run_pipeline.py --region narita kawasaki_daishi kawagoe sawara      # 動画・コメントの取得とテーマ分類
python fetch_channel_stats.py --region narita kawasaki_daishi kawagoe sawara
python compare_regions.py --region narita kawasaki_daishi kawagoe enoshima_kamakura sawara choshi --base narita
python analyze_trends_accounts.py --region narita kawasaki_daishi kawagoe enoshima_kamakura sawara choshi --base narita
python analyze_engagement_keywords.py --region narita kawasaki_daishi kawagoe enoshima_kamakura sawara choshi --base narita --base-theme 歴史・寺社
python analyze_keywords.py --region narita        # 主要キーワード
python analyze_channel_types.py                   # 競合のプロモーション手法（公式・メディア・企業・個人の作り手）
python check_robustness.py --region narita        # 集め方の偏り、少ない本数の中身、乗り継ぎの動画
python analyze_name_presence.py                   # タイトルに町の名前がある割合
python analyze_search_trends.py                   # data/trends/ に置いたGoogle TrendsのCSVの集計
```

クォータの目安は1地域あたり約2,000ユニットです（無料枠は1日10,000ユニット）。

### ダッシュボード

```
python -m streamlit run dashboard.py
```

APIは使わず、手元のデータを読み込むだけです。サイドバーで「分析の対象」と「比べる地域」を選びます。

| タブ | 見られること |
|---|---|
| まとめ | 分析の対象の課題を、データから計算した数字で1画面に。戦略の方向性と分類の精度 |
| 地域の概要 | 海外向けの割合、集中度、上位3チャンネルへの依存度、海外で見られているテーマと上位動画 |
| 国内と海外 | テーマ別の比較、空白地帯、主要キーワード、スポット・特産品の名前 |
| 地域の比較 | 比較表、投稿年ごとの推移、発信者の種類（公式・メディア・企業・個人の作り手） |
| 伸びる要因 | 重回帰分析の効果と95%信頼区間。テーマの基準（寺＝1など）を切り替えられる |
| コメント | 海外の視聴者のコメントの言語、いいねの多いコメント |
| 判定を試す | タイトルを入れると、言語・観光かどうか・テーマと、その理由が出る |
| 費用対効果 | 作り手と広告の1再生あたりの費用の比較、KPI（知る → 行く → 使う）の現状と目標 |

サイドバーには、データの取得日と、規約の30日の期限までの残り日数を表示します。

### 分類の精度の検証

```
python make_validation_sample.py --region narita --per-group 15   # 検証用の動画を選ぶ
python make_label_gallery.py --limit 30                            # サムネイルを見ながら正解を記入するページを作る
python evaluate_validation.py --all                                # これまでの検証をまとめて、テーマ別の精度も出す
```

## ファイル構成

すべてのプログラムを今の分析で使っています。使う順に並べると次のとおりです。

| 段階 | ファイル | 役割 |
|---|---|---|
| 0. 地域を決める | `new_region.py` | 地名から、多言語の検索キーワードつきの設定ファイルを作る |
| | `regions/*.json` | 地域ごとの設定。成田（分析の対象）、川崎大師、川越、江ノ島・鎌倉、佐原、銚子、大洗 |
| 1. 集める（APIを使う） | `check_youtube_volume.py` | 動画の検索と詳細の取得、言語と地域との関係の判定 |
| | `fetch_comments.py` | 上位の動画のコメント（投稿者の名前は保存しない） |
| | `fetch_channel_stats.py` | チャンネル登録者数 |
| | `run_pipeline.py` | 集める〜判定するをまとめて実行 |
| 2. 判定する | `classify_themes.py` | テーマの分類と、国内向け・海外向けの集計 |
| | `theme_rules.py` | テーマとノイズの辞書、判定のルール |
| | `lang_utils.py` | 言語判定のルール |
| 3. 分析する（APIは使わない） | `compare_regions.py` | 地域の比較（集中度、言語、動画の形式など） |
| | `analyze_trends_accounts.py` | 年ごとの推移、チャンネルへの依存度 |
| | `analyze_engagement_keywords.py` | 重回帰分析（再生数・エンゲージメント率）、スポットの集計 |
| | `analyze_keywords.py` | 主要キーワード（タイトル・説明文によく出る言葉） |
| | `analyze_channel_types.py` | 発信者の種類（公式・メディア・企業・個人の作り手） |
| | `analyze_name_presence.py` | タイトルに町の名前がある割合 |
| | `analyze_search_trends.py` | Google Trendsの集計 |
| | `check_robustness.py` | 結論の確かめ（集め方の偏り、少ない本数の中身） |
| 4. 見せる | `dashboard.py` | ダッシュボード（Streamlit） |
| 5. 精度を確かめる | `make_validation_sample.py` / `make_label_gallery.py` / `evaluate_validation.py` | 人の目の判定と比べて精度を出す |
| 共通 | `region_config.py` | 地域設定の読み込み、データの保存先 |

## データの扱い

- YouTube API Services の規約と開発者ポリシーに従い、取得したデータ（動画の情報、統計、コメント）は**このリポジトリに含めていません**（`data/` は `.gitignore` で除外）。
- 手元でも30日を超えて保存せず、期限が来たら削除するか取り直します。
- コメントの分析では、投稿者の名前などの個人情報は保存していません。
- APIキーは `.env` に書き、GitHubには上げていません。

## 分析の限界

- 検索結果は、キーワードごとに関連度の高い上位の動画のサンプルで、全投稿ではありません。
- チャンネル登録者数は取得時点の値で、動画を投稿した当時の値ではありません。
- 回帰分析は相関の分析で、「そのテーマにすれば必ず伸びる」という因果までは言えません。6地域をまとめた結果で、成田だけの結果ではありません。
- テーマの分類の精度は約6割なので、テーマ別の数字はおおよその傾向として読みます。戦略の柱になる観光判定と国内・海外の判定は約9割です。
- 主要キーワードは、国内向けは日本語、海外向けは主に英語なので、言葉の数を国内と海外で直接比べることはできません。検索キーワードに入れた言葉は多く出やすくなります。
- 分析はYouTubeとGoogle Trendsだけで、韓国のNaverや中国の小紅書など、ほかの場の動きは見えていません。
